개인정보처리방침 (Privacy Policy)

최종 수정일: 2026년 11월 21일

1. 개요

이 앱("Claude MCP")은 개인 사용자(앱 소유자) 본인의 Google 계정 데이터에만 접근하기 위한 개인 용도 OAuth 애플리케이션입니다. 일반 대중에게 배포되지 않으며, 앱 소유자 본인 외의 사용자는 사용하지 않습니다.

2. 수집하는 정보

이 앱은 사용자가 Google 계정으로 로그인하고 동의한 범위 내에서 Google Drive 등 Google API를 통해 제공되는 데이터(파일 목록, 파일 내용 등)에 접근할 수 있습니다. 이 앱은 별도의 서버에 데이터를 저장하지 않으며, 접근한 데이터는 로컬 환경에서만 처리됩니다.

3. 데이터 사용 목적

수집/접근한 데이터는 오직 앱 소유자 본인의 개인적인 생산성 작업 (문서 조회, 파일 관리 등)을 위해서만 사용되며, 그 외의 목적으로 사용되지 않습니다.

4. 데이터 공유

이 앱은 수집하거나 접근한 어떠한 사용자 데이터도 제3자와 공유, 판매, 또는 양도하지 않습니다.

5. Google API 서비스 사용자 데이터 정책

이 앱의 Google API 사용은 Google API Services User Data Policy 를 준수하며, 특히 제한된 사용(Limited Use) 요건을 준수합니다.

6. 데이터 보관 및 삭제

이 앱은 사용자의 Google 데이터를 자체 서버에 영구 저장하지 않습니다. 사용자는 언제든지 Google 계정 - 보안 - 타사 앱 및 서비스 에서 이 앱의 접근 권한을 철회할 수 있습니다.
